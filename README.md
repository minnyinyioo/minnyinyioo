1. **System Design** — Architecture, data flow, user experience on paper
2. **Code Generation** — AI (Cursor, Claude, ChatGPT) writes boilerplate and logic
3. **Review & Integrate** — Understand every line, refactor, stitch together
4. **Ship & Iterate** — Deploy to Vercel/Supabase, gather feedback, repeat
